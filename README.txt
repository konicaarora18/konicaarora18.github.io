- assets/Konica_Arora_Professional_CV.docx: downloadable CV

HOW TO PUBLISH FOR FREE (GitHub Pages):
1. Sign in or create an account at https://github.com/
2. Create a new public repository named: konicaarora.github.io
3. Upload index.html and the assets folder (keep the folder structure).
4. Open repository Settings → Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. After GitHub publishes it, your link will be:
   https://konicaarora.github.io/

The live link only becomes active after you complete the publishing steps.
You can also deploy the folder using Netlify Drop at https://app.netlify.com/drop .
